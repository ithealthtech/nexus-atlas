Chapter 14

Everyday tasks at a glance

I want to Go to
Find anything Ctrl+K, anywhere
See what's coming due Home → Expirations
Open a client Clients, or Ctrl+K and the client's name
Leave a note everyone sees on a client Edit on the client's quick note
Add a device The client's Assets tab → Add asset
Write a procedure The client's Documents tab, or Docs → Knowledge base → New document
Work through onboarding The client's Checklists tab → Start a checklist
See a password The client's Passwords tab, then the eye
Give a password to someone outside The password → Quick share
Hand over a file once Vault → Send → New Send
Keep my own login Vault → My vault → Add
Find weak or reused passwords Vault → Password health
Print a QR label The asset → QR label
Send a client their report The client's Reports tab → run a report → PDF or Share
Change my menu layout Profile & sign-in → Menu
Add a technician Admin → People & access → Add person
Reset someone's two-step sign-in People & access → Manage → Reset sign-in
Turn off a leaver People & access → Manage → tick Disable this account
Set up email Admin → Email & alerts
Bring in Hudu or ConnectWise Admin → Import & export
Make a backup now Admin → System status → Back up now
Install an update Admin → Updates
Restart a service Admin → Services
Stop the certificate warning Admin → Certificate → Download, then install it
